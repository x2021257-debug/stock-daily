# A股每日选股（多策略版）

每天收盘后自动扫一遍全市场，跑 **11 个技术形态选股策略**，再过一层信号过滤器，
最后给出**大盘择时仓位建议**，生成一个网页。

**数据源**：新浪财经公开接口（经 [akshare](https://github.com/akfamily/akshare)）。
**无需注册、无需 token、无需密钥。**

策略逻辑源自开源项目 [wei1104/bigApush](https://github.com/wei1104/bigApush)，
指标算法对齐通达信标准公式；大盘择时与风险分档借鉴
[ling-0729/KHunter](https://github.com/ling-0729/KHunter)（两者同源，均致谢 a-share-quant-selector）。

## 生效中的 15 个选股策略

| # | 策略 | 核心判据 |
|:--:|---|---|
| 1 | **连阳回调** | 3~5 连阳中出现涨幅 ≥7% 的放量日，随后回调 3~4 天不破启动位 |
| 2 | **金三角** | MA5×MA10、MA5×MA20、MA10×MA20 依次金叉形成三角 + 放量确认（宽信号，权重低） |
| 3 | **仙人指路** | 冲高回落长上影（涨 ≥6%、上影 ≥3%）+ 均线多头 + 后续站稳 5 日线 |
| 4 | **涨停回马枪** | 涨停后回调 1~9 天、缩量、不破涨停收盘价 95% |
| 5 | **启明星** | 长阴 → 小实体 → 长阳（>5%）突破 5 日线，第三根放量 ≥1.5 倍 |
| 6 | **多金叉共振** | 均线 / KDJ / MACD 三金叉在 3 日内相继发生（宽信号，权重低） |
| 7 | **多方炮** | 两阳夹一阴，第三根放量突破第一根收盘价并站上 20 日线 |
| 8 | **阻力位突破** | 放量长阳（≥8%、量 ≥2.2 倍）突破 60 日高点，回踩不破 |
| 9 | **2560战法** | 股价上穿 MA25 + 5 日均量上穿 60 日均量 + 放量收涨 |
| 10 | **趋势共振反转** | RSI 从 <30 上穿 50 + MA5 上穿 MA20 + DIF 上穿 DEA 共振 |
| 11 | **量能异动** | 量比 ≥2 + 量 ≥昨日 1.5 倍，但涨幅仅 −3%~+5%（放量不涨，疑似吸筹） |
| 12 | **龙头策略** | 严格第 2 板 + 非一字板 + 换手 5%~25% + 流通市值 ≤300 亿 + 量能温和放大 |
| 13 | **主升低吸** | 一拉(30%~100%) → 二调(回撤 ≥18%) → 今日放量长阳贴紧突破 R（≤2%） |
| 14 | **次新腰斩** | 截至信号日 K 线 ≤120 根 + 自上市最高价回撤 ≥50% |
| 15 | **超跌反弹** | 120 日跌幅 ≥50% + MACD 底背离 +（底分型/低位TD9/启明星）+ 反弹 ≤30% |

> 第 12~15 个移植自 [ling-0729/KHunter](https://github.com/ling-0729/KHunter)。
> ⚠️ **龙头策略的已知偏差**：原版用分时数据判断「封板时间 ≤11:00」（早封板），
> 本项目只有日线，无法判定封板时间，**条件因此偏宽**。
> ⚠️ 次新腰斩与超跌反弹互斥（前者只做次新、后者排除次新），均属**低频策略**，
> 单日全市场常常零命中，属正常现象。

## 大盘择时（仓位建议）

策略负责"买什么"，`timing.py` 负责"**该不该买、买多少**"。分两层：

**① 趋势维度**（沪深300 + ADX，Wilder 标准算法）

| ADX 状态 | 仓位 |
|---|---|
| ADX > 25 且上升 | 满仓 100% |
| ADX ≥ 20 且上升 且 收盘 > MA20 | 70% |
| ADX < 18 且下降 | 空仓 0% |
| 其余（过渡期） | 50% |

**② 风险维度**（中证500 + EWMA VaR）

用 EWMA(λ=0.85) 估 99% 参数法 VaR，按其在最近 500 个交易日中的分位分四档：
正常 ≤60% → 100% ｜ 注意 ≤80% → 70% ｜ 危险 ≤95% → 40% ｜ 崩溃 >95% → 0%

**最终仓位 = min(趋势仓位, 风险仓位)**，两个条件都满足才满仓。

> ⚠️ 关于"照搬 KHunter 原版"：实测最近 250 个交易日，原版规则只有 **12%** 的交易日满仓、
> **88%** 处于空仓（ADX 中位数仅 18.8），会让整个系统几乎不出手。
> 故默认改用上表的放宽档（把 ADX 20~25 的过渡区从"空仓"改为"半仓/七成仓"），
> 实测分布为 满仓 4.4% / 70%仓 12% / 50%仓 29.6% / 40%仓 25.6% / 空仓 28.4%。
> 想用原版：设环境变量 `TIMING_STRICT=1`。

## 排序与评分

- **主排序**：强信号数（剔除宽信号「金三角」「多金叉共振」后的命中数）
- **次排序**：命中策略权重之和 → 技术面五维评分（均线/RSI/MACD/量能/涨跌幅）→ 流通市值

页面顶部有筛选按钮，可只看「⭐ 有强信号」「命中 ≥2 个策略」或「≥3 个策略」。
每只股票还会显示**所属板块**（东财行业分类）与**量比**。


## 信号过滤器

策略负责「发现形态」，过滤器负责「排除不该碰的」——用"少而精"换胜率。见 `filters.py`。

| 过滤器 | 默认 | 判据 |
|---|---|---|
| **相对强度 RS** | 开 | 个股 20 日涨幅 − 沪深300 20 日涨幅 **≥ 10%** |
| **换手率** | 开 | **2% ~ 10%** |
| **量比** | 开 | 当日成交 / 5 日均量 **≥ 1.2** |
| **股价位置** | 关 | 距 120 日高点 ≤98%（默认关，会与突破类策略冲突） |

> 超跌类策略（次新腰斩、超跌反弹）**豁免 RS 检查** —— 它们天然"弱于大盘"，
> 不豁免会被 RS 全部拦死。

### 这些阈值不是拍脑袋定的

用 `optimize.py` 做**训练/测试分割**（前 60% 交易日选参数、后 40% 验证），
500 只样本、**2721 个信号**，单因子分档结果（持 5 日）：

| 因子分档 | 胜率 | 均收益 | 结论 |
|---|---|---|---|
| RS ∈ [0, 5%) | **37.5%** | −0.68% | ← 最差档，所以门槛要提高 |
| RS ∈ [5%, 15%) | 45.7% | −0.71% | 最好档 |
| 换手率 ∈ [2%, 5%) | 41.0% | −1.04% | |
| 换手率 ∈ [5%, 10%) | **46.6%** | **+0.03%** | ← 唯一正收益档 |
| 换手率 > 10% | 39.3% | −0.84% | 游资博弈，反而差 |
| 量比 < 0.8 | 39.3% | −0.78% | |
| 量比 ≥ 2.0 | **46.4%** | **+0.08%** | ← 越活跃越好 |
| 距 120 日高点 ∈ [0.80, 0.90) | **35.3%** | −1.32% | ← 中间位置最差 |
| 距 120 日高点 > 0.97 | 45.9% | +0.53% | 强者恒强 |
| RSI > 70 | 47.8% | +0.42% | 强者恒强 |

**一个反直觉但稳定的规律：「不上不下的中间状态」胜率最低。**
（RS 0~5%、位置 0.8~0.9、20 日涨幅 −5%~+5% 都是各自最差档）
—— 要么足够强，要么深度超跌，中间地带没有方向。

**样本外验证**（测试集 1258 个信号）：

| 配置 | 训练集胜率 | **测试集胜率** |
|---|---|---|
| 不过滤（基准） | 40.4% | 43.2% |
| RS≥10% + 量比≥1.2 + 换手 2~8% | 55.2% | **47.7%** |

⚠️ **注意训练集 55.2% → 测试集 47.7% 这个衰减**，这就是过拟合的典型表现。
**样本外胜率提升到 47.7%（比基准高 4.5pp），但依然低于 50%** —— 这是诚实的边界。

## 回测结果（务必读）

`backtest3.py`：**400 只随机样本 · 393 只有效 · 189 个信号**（已过新过滤器）·
**T+1 开盘成交 · 已扣 0.25% 往返成本** · 样本期约 176 个交易日。

### ① 单笔胜率

| 持有期 | 样本 | **胜率** | 平均收益 | 中位数 | 盈亏比 |
|---|---|---|---|---|---|
| **5 日** | 189 | **49.2%** | **+0.20%** | −0.25% | 1.09 |
| 10 日 | 189 | 48.1% | −0.50% | −0.61% | 0.95 |
| 20 日 | 189 | 38.6% | −1.78% | −2.25% | 1.15 |

> 5 日已接近 50%，**平均收益首次转正**。10/20 日反而变差 —— 说明这套信号的
> 有效期在 5 个交易日左右，拿久了会回吐。

### ② 组合净值（日度持仓模型）

| 持有期 | 配置 | 日胜率 | 累计净值 | 年化 | **最大回撤** | 夏普 |
|---|---|---|---|---|---|---|
| **5 日** | 不加择时 | 53.9% | 1.0467 | **+12.0%** | −21.16% | 0.49 |
| **5 日** | **加大盘择时** | **56.2%** | **1.0902** | **+23.9%** | **−9.23%** | **1.53** |
| 10 日 | 不加择时 | 53.3% | 0.9077 | −20.5% | −22.30% | −0.65 |
| 10 日 | 加大盘择时 | 54.1% | 0.9916 | −2.0% | −9.65% | −0.10 |
| 20 日 | 不加择时 | 51.3% | 0.9198 | −15.9% | −17.52% | −0.43 |
| 20 日 | 加大盘择时 | 53.7% | 1.0134 | +2.8% | −6.07% | 0.30 |

基准：同期沪深300 买入持有 **−6.4%**。

### ③ 优化前后对比（同样是 400 只样本）

| 指标 | 优化前 | **优化后** |
|---|---|---|
| 策略数 | 17（未归档） | 15（归档 7 个 + 新增 4 个） |
| 过滤器 | RS≥0%、换手 0.5~15% | **RS≥10%、换手 2~10%、量比≥1.2** |
| 信号数 | 909 | **189**（更精简） |
| 5 日胜率 | 44.3% | **49.2%** |
| 5 日均收益 | −0.63% | **+0.20%** |
| 组合年化（加择时） | −3.3% | **+23.9%** |
| 最大回撤（加择时） | −9.15% | −9.23% |
| 夏普（加择时） | −0.31 | **1.53** |

### ④ 结论与边界（重要）

1. **提升主要来自「提高因子门槛」，不是来自加策略**
   把 RS 从 0 提到 10%、换手率收窄到 2~10%、加量比门槛 —— 信号砍掉 79%，胜率提升 4.9pp。
2. **大盘择时依然是关键的一环**：持 5 日年化从 +12.0% 提到 +23.9%，回撤砍掉 56%。
3. ⚠️ **这个回测不是纯样本外**
   过滤参数是在 500 只样本上搜出来的，本次回测用的 400 只**与它部分重叠**。
   纯样本外的证据在 `optimize.py` 的测试集：**胜率 47.7%（基准 43.2%）**。
   两者有差距（49.2% vs 47.7%），差距就是参数选择的乐观偏差，**这很常见但必须说出来**。
4. ⚠️ **样本期只有约半年**，且期间市场偏弱（基准 −6.4%）。
5. ⚠️ **未知偏差**：幸存者偏差、前复权轻微前视（数据源特性），已在下方自检表标注。

### ⑤ 一个反直觉的发现

「多信号叠加更准」在**这个过滤器下并不成立**，甚至相反：

| 非宽信号命中数 | 样本 | 胜率 | 平均收益 |
|---|---|---|---|
| 0 个（仅金三角/多金叉共振） | 163 | 52.8% | +0.42% |
| 1 个 | 25 | 28.0% | −1.02% |

原因推测：过滤器已经强制要求"强于大盘 10% + 换手适中 + 放量"，能通过的都是强势股；
在这个前提下，均线金叉类信号（金三角）反而恢复了有效性。
（但 25 个样本太小，这一条仅供参考，别当结论。）

**这套东西的定位仍然是「关注列表生成器 + 仓位提示器」——
把 5000 只缩到几十只供人工研究，再加一句"今天该不该重仓"，不是交易系统。**

## 数据更新时点（重要）

新浪的**日线历史接口**当天数据要等到晚上才更新（实测下午 16:18 还没更、22:59 才有）。
但**实时快照接口**收盘后立刻就是收盘价，且带完整 OHLC。

所以程序采用**快照拼接**：

1. 日线取到 T-1
2. 从快照补出 T 日（开/高/低/收/量）
3. 拼接后计算指标、跑策略

**安全校验**：只有快照的「昨收」≈日线最后一天收盘（差 <0.5%）时才拼接——
否则说明中间有除权、复权口径对不上，宁可不拼也不拼错。

效果：**收盘后十几分钟就能出结果**，不必等到深夜。

## 三个回测脚本

| 脚本 | 做什么 |
|---|---|
| `backtest.py` | **策略层**：逐个策略统计信号出现后 5/10/20 日的胜率与收益，带同批样本基准对照 |
| `backtest2.py` | **组合层 v2**：日度持仓组合模型（T 日收盘成交口径——含前视偏差，仅作历史对照） |
| `backtest3.py` | **组合层 v3** ★推荐：T+1 开盘成交 + 大盘择时控仓 + 多持有期对比 |

```bash
python backtest3.py
# 或自定义：BT_POOL=400 BT_STEP=3 BT_HOLDS=5,10,20 python backtest3.py
```

- 股票池：全市场随机采样（固定随机种子，可复现）
- 信号日：从第 130 个交易日起每隔 N 天取一个（默认 3）
- 输出：单笔胜率（多持有期）、组合净值/年化/最大回撤/夏普（不择时 vs 择时）、
  分信号数胜率、分策略胜率
- 结果存 `backtest3_result.json`

> ⚠️ 注意：**必须串行跑**。akshare 依赖的 py_mini_racer（V8 引擎）
> 不是线程安全的，多线程并发调用会 `FATAL` 崩溃。

## 怎么用

### 全自动（推荐）

1. 仓库主页 → **Settings** → 左侧 **Pages**
2. 「Source」选 **GitHub Actions**，保存
3. 仓库主页 → **Actions** → 左侧「每日选股」→ 右侧 **Run workflow** 手动跑一次
4. 跑完后访问 `https://<你的用户名>.github.io/<仓库名>/`

之后每个工作日北京时间 **15:30** 自动运行并更新网页，不用管。

### 本地运行

```bash
pip install -r requirements.txt
python screen.py
```

结果在 `docs/index.html`，用浏览器打开即可。
