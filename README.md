# A股每日选股（多策略版）

每天收盘后自动扫一遍全市场，跑 **17 个技术形态选股策略**，筛出值得关注的股票，生成一个网页。

**数据源**：新浪财经公开接口（经 [akshare](https://github.com/akfamily/akshare)）。
**无需注册、无需 token、无需密钥。**

策略逻辑移植自开源项目 [wei1104/bigApush](https://github.com/wei1104/bigApush)，
取其 19 个策略中的 17 个全市场选股策略（另 2 个一个是择时策略、一个源码中无实现），
指标算法对齐通达信标准公式。

## 17 个选股策略

| # | 策略 | 核心判据 |
|:--:|---|---|
| 1 | **底部趋势拐点** | 120 日内跌幅 >45% + MACD 底背离 + 放量反弹 >8%（量 >2.5 倍） |
| 2 | **连阳回调** | 3~5 连阳中出现涨幅 ≥7% 的放量日，随后回调 3~4 天不破启动位 |
| 3 | **金叉不绿** | MACD 零轴上金叉 + 金叉前绿柱 ≤3 根 + 布林带张口扩大 |
| 4 | **金三角** | MA5×MA10、MA5×MA20、MA10×MA20 依次金叉形成三角 + 放量确认 |
| 5 | **仙人指路** | 冲高回落长上影（涨 ≥6%、上影 ≥3%）+ 均线多头 + 后续站稳 5 日线 |
| 6 | **涨停回马枪** | 涨停后回调 1~9 天、缩量、不破涨停收盘价 95% |
| 7 | **涨停横盘** | 涨停后横盘 1~8 天（振幅 +5%/-2%）+ 缩量 + 放量突破 |
| 8 | **启明星** | 长阴 → 小实体 → 长阳（>5%）突破 5 日线，第三根放量 ≥1.5 倍 |
| 9 | **多金叉共振** | 均线 / KDJ / MACD 三金叉在 3 日内相继发生 |
| 10 | **多方炮** | 两阳夹一阴，第三根放量突破第一根收盘价并站上 20 日线 |
| 11 | **阻力位突破** | 放量长阳（≥8%、量 ≥2.2 倍）突破 60 日高点，回踩不破 |
| 12 | **2560战法** | 股价上穿 MA25 + 5 日均量上穿 60 日均量 + 放量收涨 |
| 13 | **强势洗盘弱转强** | 放量大阳 → 放量阴线洗盘 → 3 日内反包走强 |
| 14 | **趋势加速拐点** | 上升趋势（R²>0.5）中放量长阳（≥8%、量 ≥2 倍）开启加速 |
| 15 | **趋势共振反转** | RSI 从 <30 上穿 50 + MA5 上穿 MA20 + DIF 上穿 DEA 共振 |
| 16 | **趋势起点** | MACD 零轴上金叉 + 收盘上穿布林中轨 + 放量阳线站上 5 日线 |
| 17 | **W底** | 40 日内双底（两底差 ≤3%、间隔 ≥10 日）+ 放量突破颈线 |

> 注：bigApush 的「海龟策略」是择时策略（判断持仓买卖、不做全市场筛选），
> 「520560策略」在其源码中无实现，故未移植。

## 排序与评分

- **主排序**：命中策略的权重之和（权重取自 bigApush 各策略的 `strategy_weight`）
- **次排序**：技术面五维评分（均线排列 / RSI / MACD / 量能 / 涨跌幅），0~100

页面顶部有筛选按钮，可只看「命中 ≥2 个策略」或「≥3 个策略」的股票——
命中越多通常信号越强，单信号股票的参考价值相对低。

每只股票还会显示**所属板块**（东财行业分类，如「化学制品」「通信设备」「银行Ⅱ」）。

## 信号过滤器

策略负责「发现形态」，过滤器负责「排除不该碰的」——用"少而精"换胜率。见 `filters.py`。

| 过滤器 | 默认 | 判据 |
|---|---|---|
| **相对强度 RS** | 开 | 个股 20 日涨幅 − 沪深300 20 日涨幅 ≥ 0（只买强于大盘的） |
| **换手率** | 开 | 0.5% ~ 15%（排除无人问津与游资博弈） |
| **股价位置** | 关 | 距 120 日高点 ≤98%（默认关，会与突破类策略冲突） |

实测：200 只候选 → 38 只命中策略 → **16 只通过过滤器**（22 只因"弱于大盘"被拦）。

## 回测结论（务必读）

`backtest2.py` 用**日度持仓组合模型**（400 只随机样本、最近半年、扣 0.25% 往返成本）：

| 指标 | 不过滤 | 加过滤器 | 基准(沪深300) |
|---|---|---|---|
| 日均持仓 | 78.0 只 | 51.2 只 | — |
| 日胜率 | 50.4% | 50.0% | — |
| 年化收益 | −43.0% | **−35.3%** | −6.4% |
| 最大回撤 | −29.5% | **−26.8%** | — |
| 夏普 | −2.33 | −1.64 | — |

**结论**：
1. 过滤器**确实有效**（年化 +7.7pp、回撤改善 2.7pp、夏普改善 0.7），但**不足以转正**
2. 持有 5 日、每天换手 → 一年约 48 轮 × 0.25% ≈ **年化 12% 的交易成本**，这是重要拖累
3. **样本期只有半年且市场偏弱**（基准 −6.4%），不能据此断言长期无效，但也**绝不能当成赚钱工具**

> ⚠️ **回测方法论提醒**：交易笔数少于 30 的结论不可信。
> 本项目早期用"串行单笔"模型只得到 19~20 笔交易，结果波动极大（年化 −20% ~ +99%，纯运气）；
> 换成日度持仓模型后样本才够，结论才稳定。

> ⚠️ 已知偏差：股票池取"当前上市"的股票，**存在幸存者偏差**（退市股不在内），历史结果偏乐观。

**这套东西的正确定位是「关注列表生成器」——把 5000 只缩到几十只供人工研究，不是交易系统。**

部署方式（GitHub Actions vs 本地）见 [DEPLOY.md](DEPLOY.md)。

## 数据更新时点（重要）

新浪的**日线历史接口**当天数据要等到晚上才更新（实测下午 16:18 还没更、22:59 才有）。
但**实时快照接口**收盘后立刻就是收盘价，且带完整 OHLC。

所以程序采用**快照拼接**：

1. 日线取到 T-1
2. 从快照补出 T 日（开/高/低/收/量）
3. 拼接后计算指标、跑策略

**安全校验**：只有快照的「昨收」≈日线最后一天收盘（差 <0.5%）时才拼接——
否则说明中间有除权、复权口径对不上，宁可不拼也不拼错。

效果：**收盘后十几分钟就能出结果**，不必等到深夜。

## 策略回测

`backtest.py` 用于统计各策略的历史表现（信号出现后 5/10/20 日的胜率与收益）：

```bash
python backtest.py
```

- 股票池：全市场随机采样（默认 200 只，固定随机种子，可复现）
- 信号日：从第 120 个交易日起每隔 N 天取一个（默认 4）
- 输出：每个策略的触发次数、胜率、平均收益，以及**同批样本的基准收益**做对照
- 结果存 `backtest_result.json`

> ⚠️ 注意：`backtest.py` **必须串行跑**。akshare 依赖的 py_mini_racer（V8 引擎）
> 不是线程安全的，多线程并发调用会 `FATAL` 崩溃。

## 自动排除

- 北交所
- ST / *ST / 退市 / PT
- 停牌（成交量异常）
- 成交额低于 8000 万（流动性太差）
- 60 日涨幅超过 90%（防追高）

## 怎么用

### 全自动（推荐）

1. 仓库主页 → **Settings** → 左侧 **Pages**
2. 「Source」选 **GitHub Actions**，保存
3. 仓库主页 → **Actions** → 左侧「每日选股」→ 右侧 **Run workflow** 手动跑一次
4. 跑完后访问 `https://<你的用户名>.github.io/<仓库名>/`

之后每个工作日北京时间 **15:30** 自动运行并更新网页，不用管。

### 本地运行

```bash
pip install -r requirements.txt
python screen.py
```

结果在 `docs/index.html`，用浏览器打开即可。

## 可调参数（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `MAX_CANDIDATES` | 1200 | 按成交额排序后精算的股票数上限，调小可加快运行 |
| `SCREEN_WORKERS` | 6 | 并发抓取线程数 |
| `MIN_AMOUNT` | 80000000 | 成交额下限（元） |
| `KLINE_LEN` | 250 | 每只股票回溯的日线根数 |
