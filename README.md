# A股每日选股（多策略版）

每天收盘后自动扫一遍全市场，跑 **17 个技术形态选股策略**，筛出值得关注的股票，生成一个网页。

**数据源**：新浪财经公开接口（经 [akshare](https://github.com/akfamily/akshare)）。
**无需注册、无需 token、无需密钥。**

策略逻辑移植自开源项目 [wei1104/bigApush](https://github.com/wei1104/bigApush)，
取其 19 个策略中的 17 个全市场选股策略（另 2 个一个是择时策略、一个源码中无实现），
指标算法对齐通达信标准公式。

## 17 个选股策略

| # | 策略 | 核心判据 |
|:--:|---|---|
| 1 | **底部趋势拐点** | 120 日内跌幅 >45% + MACD 底背离 + 放量反弹 >8%（量 >2.5 倍） |
| 2 | **连阳回调** | 3~5 连阳中出现涨幅 ≥7% 的放量日，随后回调 3~4 天不破启动位 |
| 3 | **金叉不绿** | MACD 零轴上金叉 + 金叉前绿柱 ≤3 根 + 布林带张口扩大 |
| 4 | **金三角** | MA5×MA10、MA5×MA20、MA10×MA20 依次金叉形成三角 + 放量确认 |
| 5 | **仙人指路** | 冲高回落长上影（涨 ≥6%、上影 ≥3%）+ 均线多头 + 后续站稳 5 日线 |
| 6 | **涨停回马枪** | 涨停后回调 1~9 天、缩量、不破涨停收盘价 95% |
| 7 | **涨停横盘** | 涨停后横盘 1~8 天（振幅 +5%/-2%）+ 缩量 + 放量突破 |
| 8 | **启明星** | 长阴 → 小实体 → 长阳（>5%）突破 5 日线，第三根放量 ≥1.5 倍 |
| 9 | **多金叉共振** | 均线 / KDJ / MACD 三金叉在 3 日内相继发生 |
| 10 | **多方炮** | 两阳夹一阴，第三根放量突破第一根收盘价并站上 20 日线 |
| 11 | **阻力位突破** | 放量长阳（≥8%、量 ≥2.2 倍）突破 60 日高点，回踩不破 |
| 12 | **2560战法** | 股价上穿 MA25 + 5 日均量上穿 60 日均量 + 放量收涨 |
| 13 | **强势洗盘弱转强** | 放量大阳 → 放量阴线洗盘 → 3 日内反包走强 |
| 14 | **趋势加速拐点** | 上升趋势（R²>0.5）中放量长阳（≥8%、量 ≥2 倍）开启加速 |
| 15 | **趋势共振反转** | RSI 从 <30 上穿 50 + MA5 上穿 MA20 + DIF 上穿 DEA 共振 |
| 16 | **趋势起点** | MACD 零轴上金叉 + 收盘上穿布林中轨 + 放量阳线站上 5 日线 |
| 17 | **W底** | 40 日内双底（两底差 ≤3%、间隔 ≥10 日）+ 放量突破颈线 |

> 注：bigApush 的「海龟策略」是择时策略（判断持仓买卖、不做全市场筛选），
> 「520560策略」在其源码中无实现，故未移植。

## 排序与评分

- **主排序**：命中策略的权重之和（权重取自 bigApush 各策略的 `strategy_weight`）
- **次排序**：技术面五维评分（均线排列 / RSI / MACD / 量能 / 涨跌幅），0~100

页面顶部有筛选按钮，可只看「命中 ≥2 个策略」或「≥3 个策略」的股票——
命中越多通常信号越强，单信号股票的参考价值相对低。

## 自动排除

- 北交所
- ST / *ST / 退市 / PT
- 停牌（成交量异常）
- 成交额低于 8000 万（流动性太差）
- 60 日涨幅超过 90%（防追高）

## 怎么用

### 全自动（推荐）

1. 仓库主页 → **Settings** → 左侧 **Pages**
2. 「Source」选 **GitHub Actions**，保存
3. 仓库主页 → **Actions** → 左侧「每日选股」→ 右侧 **Run workflow** 手动跑一次
4. 跑完后访问 `https://<你的用户名>.github.io/<仓库名>/`

之后每个工作日北京时间 **15:30** 自动运行并更新网页，不用管。

### 本地运行

```bash
pip install -r requirements.txt
python screen.py
```

结果在 `docs/index.html`，用浏览器打开即可。

## 可调参数（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `MAX_CANDIDATES` | 1200 | 按成交额排序后精算的股票数上限，调小可加快运行 |
| `SCREEN_WORKERS` | 6 | 并发抓取线程数 |
| `MIN_AMOUNT` | 80000000 | 成交额下限（元） |
| `KLINE_LEN` | 250 | 每只股票回溯的日线根数 |

## 目录结构

```
screen.py                         主程序：抓数据 → 算指标 → 跑 17 策略 → 出网页
strategies.py                     17 个选股策略 + 技术指标计算
requirements.txt                  依赖
docs/index.html                   生成的网页（GitHub Pages 发布目录）
docs/data.json                    结构化的选股结果
.github/workflows/daily.yml       定时任务
```
